# Prüfexemplare ohne Freigabe

Hier liegen textfreie Artwork-Master, die zur Abnahme gezeigt wurden, aber
noch **nicht** durch den Nutzer freigegeben sind. Sie werden nicht von den
PDF-Konfigurationen oder vom Produktions-Promoter verwendet. Ein abgelegter
Master darf erst nach einer gesonderten, hashgebundenen Abnahme und technischer
Provenienzprüfung in `assets/posters` übernommen werden.
